Every file SynKitab opens

128 kinds of file, each shown as itself: nothing is converted on the way in, and nothing is uploaded to read it. SynKitab is a reader. It opens these to read, listen to and mark up, and does not edit them, apart from page tools for PDFs (reorder, rotate, crop, merge and split).
